# اتصال Cursor

> ⚠️ **یادداشت داخلی (قبل از انتشار حذف شود):** مستندات رسمی Cursor برای این بخش در دسترس نبود و مراحل از راهنمای‌های عمومی گرفته شده. اسم منوها و محدودیت‌ها (مثلاً حالت Agent با مدل سفارشی) باید روی Cursor واقعی تأیید شود.

Cursor اجازه می‌دهد آدرس API سازگار با OpenAI و کلید خودتان را وارد کنید. با این کار می‌توانید مدل‌های ستون را در Cursor انتخاب کنید.

---

## پیش‌نیازها

- Cursor نصب‌شده
- کلید API از صفحه‌ی **کلیدهای API** ([شروع سریع](01-quickstart.md))

---

## تنظیمات

1. Cursor Settings را باز کنید و به بخش **Models** بروید.
2. پایین‌تر، بخش **API Keys** را پیدا کنید.
3. در بخش OpenAI، **کلید ستون** را وارد کنید.
4. گزینه‌ی **Override OpenAI Base URL** را روشن کنید و این آدرس را بنویسید:

   ```
   https://api.intelligence.sotoon.ir/inference/v1
   ```

5. روی **Add Custom Model** بزنید و شناسه‌ی مدل را دقیقاً همان‌طور که در `GET /models` یا صفحه‌ی **مدل‌ها** آمده وارد کنید (`MODEL_ID`).
6. روی **Verify** (یا Save) بزنید. Cursor یک درخواست آزمایشی می‌فرستد. اگر تأیید شد، تنظیمات درست است.
7. در پنجره‌ی Chat مدل تازه‌اضافه‌شده را انتخاب کنید.

هر مدل جدیدی که خواستید، با همان روش (مرحله ۵) اضافه کنید.

---

## نکات مهم

- **کلید و آدرس ستون، جایگزین کلید OpenAI می‌شود.** اگر Cursor را با کلید واقعی OpenAI هم استفاده می‌کنید، مراقب باشید مدل‌ها قاطی نشوند.
- برای مدل‌هایی که ابزار (Tool Calling) را پشتیبانی نمی‌کنند، ممکن است بعضی قابلیت‌های Agent کار نکند. مشخصات مدل را در صفحه‌ی **مدل‌ها** ببینید.

---

## اگر کار نکرد

| نشانه | راه‌حل |
|---|---|
| Verify خطا می‌دهد | آدرس باید دقیقاً `.../inference/v1` باشد (بدون `/chat/completions` در انتها) و کلید درست باشد. |
| خطای `401` | کلید را دوباره کپی کنید. |
| `Invalid model name` | شناسه‌ی مدل غلط است. لیست مدل‌ها را دوباره بگیرید. |
| مدل در لیست نیست | مدل را با **Add Custom Model** اضافه کنید. Cursor خودش مدل‌های ستون را نمی‌شناسد. |
