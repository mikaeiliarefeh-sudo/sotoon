## صفحه ۲: مرجع API

- [ ] بازه‌ی دقیق سقف بودجه (۳۰ روز غلتان یا ماه شمسی) و زمان ریست؛ ناسازگاری کارت بودجه (۲۷.۹۲$) با «کل هزینه ۷ روز» (۵۱.۸۵$)
- [ ] هزینه‌ی توکن‌های reasoning (در `completion_tokens` شمرده می‌شود؛ هزینه‌اش تأیید نشده)
- [ ] رفتار cache فقط برای Claude از `/chat/completions` تست شده (OpenAI و بقیه نه)
- [ ] مارجین ۱۵٪ در مبلغ مشتری اعمال نمی‌شود (باگ/تصمیم؛ فرمول داکیومنت «قیمت صفحه‌ی مدل‌ها × توکن» را حفظ کرده‌ایم)
- حذف‌شده از داکیومنت چون تأیید نشده بود: `POST /responses`، پارامتر کنترل میزان تفکر (`reasoning_effort` و `reasoning.effort`)
