# اتصال Claude Code

> ⚠️ **یادداشت داخلی (قبل از انتشار حذف شود):** این صفحه هنوز روی Claude Code واقعی تست نشده. هر جا ⚠️ هست باید با یک بار اجرا تأیید شود.

Claude Code یک دستیار کدنویسی است که داخل ترمینال شما اجرا می‌شود و کد پروژه را می‌خواند، تغییر می‌دهد و دستورها را اجرا می‌کند. می‌توانید آن را به ستون وصل کنید و با مدل‌های ستون کار کنید.

اتصال فقط با دو متغیر محیطی انجام می‌شود: **آدرس** و **کلید**.

---

## پیش‌نیازها

- یک کلید API از صفحه‌ی **کلیدهای API** ([شروع سریع](01-quickstart.md))
- Node.js نصب‌شده
- Claude Code نصب‌شده. اگر ندارید، طبق راهنمای رسمی نصب کنید یا از این دستور استفاده کنید:

```bash
npm install -g @anthropic-ai/claude-code
```

---

## ۱. تنظیم آدرس و کلید

### macOS و Linux

این دو خط را به انتهای فایل `~/.zshrc` (یا `~/.bashrc`) اضافه کنید:

```bash
export ANTHROPIC_BASE_URL="https://api.intelligence.sotoon.ir/inference"
export ANTHROPIC_AUTH_TOKEN="کلید-شما"
```

بعد ترمینال را ببندید و دوباره باز کنید، یا این را بزنید:

```bash
source ~/.zshrc
```

### Windows (PowerShell)

```powershell
setx ANTHROPIC_BASE_URL "https://api.intelligence.sotoon.ir/inference"
setx ANTHROPIC_AUTH_TOKEN "کلید-شما"
```

بعد از `setx` باید PowerShell را ببندید و دوباره باز کنید.

> ⚠️ *نیاز به تأیید:* در مستند قبلی نوشته شده بود آدرس باید با `/` تمام شود (`.../inference/`). لازم است هر دو حالت (با اسلش و بدون اسلش) امتحان شود و حالتی که کار می‌کند اینجا بماند.

> **کلید را در مخزن Git یا فایل‌هایی که به اشتراک می‌گذارید ننویسید.**

## ۲. انتخاب مدل

Claude Code به‌طور پیش‌فرض دنبال مدل‌های Claude می‌گردد. برای ستون باید اسم مدل را خودتان مشخص کنید. اسم را از صفحه‌ی **مدل‌ها** یا از `GET /models` بردارید ([مرجع API](02-api-reference.md)).

```bash
claude --model MODEL_ID
```

یا برای اینکه هر بار ننویسید:

```bash
export ANTHROPIC_MODEL="MODEL_ID"
```

### مدل سبک برای کارهای پس‌زمینه ⚠️

Claude Code برای کارهای کوچک و سریع (مثل ساختن عنوان گفتگو) از یک مدل سبک جدا استفاده می‌کند. اگر آن مدل در ستون وجود نداشته باشد، ممکن است خطای «مدل پیدا نشد» ببینید. در این حالت یک مدل سبک و ارزان از لیست انتخاب کنید و این‌طور تنظیم کنید:

```bash
export ANTHROPIC_DEFAULT_HAIKU_MODEL="MODEL_ID_سبک"
```

> ⚠️ *نیاز به تأیید:* آیا این خطا واقعاً پیش می‌آید و این متغیر مشکل را حل می‌کند؟

### چه مدلی انتخاب کنم؟

Claude Code برای کار کردن به **فراخوانی ابزار (Tool Calling)** نیاز دارد. مدلی انتخاب کنید که این قابلیت را داشته باشد و context بزرگ‌تری بدهد. مشخصات هر مدل در صفحه‌ی **مدل‌ها** آمده است.

## ۳. بررسی اتصال

در پوشه‌ی یک پروژه اجرا کنید:

```bash
claude
```

یک پیام ساده بفرستید، مثلاً «این پروژه چه می‌کند؟». اگر جواب گرفتید، اتصال برقرار است.

---

## اگر کار نکرد

| نشانه | دلیل احتمالی | راه‌حل |
|---|---|---|
| خطای `401` یا `Authentication Error` | کلید اشتباه یا باطل شده | کلید را دوباره از صفحه‌ی «کلیدهای API» کپی کنید و متغیر `ANTHROPIC_AUTH_TOKEN` را چک کنید. |
| `Invalid model name` | اسم مدل غلط است یا کلید شما به آن دسترسی ندارد | لیست مدل‌ها را بگیرید و اسم را دقیقاً کپی کنید. |
| هیچ پاسخی نمی‌آید | مشکل اتصال یا آدرس | اینترنت و VPN را چک کنید و آدرس پایه را با/بدون `/` امتحان کنید. |
| Claude Code هنوز به سرویس اصلی وصل می‌شود | متغیرها اعمال نشده‌اند | ترمینال را ببندید و دوباره باز کنید. با `echo $ANTHROPIC_BASE_URL` مقدار را ببینید. |
| پاسخ خالی یا ناقص | سقف توکن مدل reasoning | در [مرجع API](02-api-reference.md) بخش «پاسخ خالی» را ببینید. |

برای تشخیص سریع اینکه مشکل از کلید یا شبکه است، این دستور را بزنید. اگر لیست مدل‌ها برگشت، کلید و آدرس درست است:

```bash
curl https://api.intelligence.sotoon.ir/inference/v1/models \
  -H "Authorization: Bearer $ANTHROPIC_AUTH_TOKEN"
```

## هزینه

هزینه‌ی استفاده از Claude Code دقیقاً مثل استفاده‌ی مستقیم از API است و بر اساس توکن حساب می‌شود. Claude Code معمولاً درخواست‌های زیادی می‌فرستد و context بزرگی دارد، پس مصرف را در صفحه‌ی **مصرف** زیر نظر داشته باشید.
